# CRM تماس و تخصیص سفر رانندگان کسبی

## چی ساخته شده؟
- ورود تیمی با ایمیل/رمز عبور (۵ نفر، هرکدوم جدا)
- لیست راننده‌ها + جستجو
- ثبت تماس برای هر راننده (تاریخ سفر، شناسه سفر، نتیجه تماس، توضیحات)
- تاریخچه کامل تماس‌های هر راننده، با اسم کسی که ثبت کرده
- تب یادآوری‌ها: لیست تماس‌هایی که باید امروز پیگیری بشن (وقتی سیستم باز باشه نشون داده میشه)
- وارد کردن راننده‌ها مستقیم از فایل اکسل گوگل‌شیتت (تشخیص خودکار ستون‌ها)

## مرحله ۱: ساخت پروژه Firebase (رایگان)
۱. برو به https://console.firebase.google.com و با جیمیلت وارد شو
۲. Add Project بزن، یه اسم بذار (مثلاً kasbi-crm) و پروژه رو بساز
۳. از منوی سمت چپ: **Build > Authentication** برو، دکمه Get Started بزن
۴. تب Sign-in method، گزینه **Email/Password** رو فعال کن
۵. برو تب **Users**، و با دکمه Add user، ۵ نفر تیمت رو اضافه کن (ایمیل دلخواه مثلاً ali@kasbi.local + یه رمز عبور برای هرکدوم)
۶. از منوی سمت چپ: **Build > Firestore Database** برو، Create Database بزن، حالت **Production mode** رو انتخاب کن، نزدیک‌ترین منطقه رو بزن

## مرحله ۲: تنظیم قوانین دسترسی Firestore
توی Firestore Database برو تب **Rules** و این رو جایگزین کن:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

این یعنی فقط کاربرهای لاگین‌کرده (همون ۵ نفر تیمت) به دیتا دسترسی دارن. Publish رو بزن.

## مرحله ۳: گرفتن کلید پروژه و اتصال فایل‌ها
۱. توی Firebase از آیکون چرخ‌دنده بالا سمت چپ برو **Project Settings**
۲. پایین صفحه، بخش "Your apps"، آیکون `</>` (Web) رو بزن، یه اسم بده و Register کن
۳. یه کد نمونه بهت میده شامل `firebaseConfig = {...}` — این مقادیر رو کپی کن
۴. فایل `firebase-config.js` رو باز کن و مقادیر داخلش رو با مقادیر خودت جایگزین کن

## مرحله ۴: آپلود روی GitHub و فعال‌سازی GitHub Pages
۱. یه ریپازیتوری جدید توی گیت‌هاب بساز (مثلاً kasbi-crm)
۲. سه فایل `index.html`، `app.html`، `firebase-config.js` رو توش آپلود کن
۳. برو تنظیمات ریپازیتوری (Settings) > بخش **Pages**
۴. زیر Source، شاخه (Branch) رو `main` و پوشه رو `/root` انتخاب کن و Save بزن
۵. بعد چند دقیقه یه لینک شبیه این بهت میده: `https://username.github.io/kasbi-crm/`
۶. همین لینک رو با ۵ نفر تیمت به اشتراک بذار

## نکات مهم
- **دیتای اولیه:** بعد از بالا اومدن سایت، وارد شو، برو تب «ورود از اکسل»، فایل اکسل گوگل‌شیتت رو آپلود کن، شیت (استان) موردنظر رو انتخاب کن و وارد کن. چون فایلت خیلی شیت داره، باید هر شیت رو جدا وارد کنی.
- **یادآوری/آلارم:** این نسخه یادآوری‌ها رو فقط وقتی که کسی سایت رو باز کرده نشون میده (توی تب یادآوری‌ها، با علامت "امروز" یا "دیرشده"). اعلان پوش واقعی (حتی وقتی سایت بسته‌ست) نیاز به زیرساخت بیشتری داره (Firebase Cloud Messaging) — اگه لازمش داری بگو تا در مرحله بعد اضافه کنم.
- **همگام‌سازی خودکار روزانه با گوگل‌شیت:** فعلاً ورود دیتا دستی و از طریق آپلود فایله. برای خودکارسازی کامل (اینکه هر سطر جدید توی گوگل‌شیت خودش بیاد تو سیستم) باید یه Google Apps Script روی خود شیت نصب بشه — این یه قدم جداست، بگو تا برات بسازم.
- اگه موقع باز شدن تب «یادآوری‌ها» توی کنسول مرورگر ارور "requires an index" دیدی، فقط روی لینکی که Firebase توی همون ارور میده کلیک کن تا ایندکس لازم خودکار ساخته بشه (یک‌بار مصرف).
